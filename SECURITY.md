# Security Policy

## Reporting Vulnerabilities

Report suspected vulnerabilities privately through GitHub private vulnerability
reporting for this repository. If private reporting is not enabled, open a
minimal public issue asking for a private contact path and do not include
exploit details, private transcripts, credentials, tokens, model files, or
personal meeting data.

Please include:

- Affected version or commit.
- The vulnerable component or flow.
- Reproduction steps that avoid sharing private meeting content.
- Impact and any known mitigations.

## Supported Versions

This project is pre-1.0. Security fixes target the main branch until public
release branches are introduced.

## Data Handling Expectations

Curiosity Transcripts is local-first. Security reports should treat recordings,
transcripts, summaries, provider keys, calendar data, and local model paths as
private user data.
